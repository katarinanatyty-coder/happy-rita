# 🎂 Сайт-поздравление для Ритули

## Структура файлов

```
/
├── index.html          ← главный файл сайта
├── song.mp3            ← твой файл с музыкой (переименуй в song.mp3)
├── images/
│   ├── vladivostok.png ← фон экрана 2
│   ├── mirror.jpg      ← фото для зеркала (экран 6)
│   ├── photo1.jpg      ← галерея (экраны 5)
│   ├── photo2.jpg
│   ├── photo3.jpg
│   ├── photo4.jpg
│   ├── photo5.jpg
│   ├── photo6.jpg
│   ├── photo7.jpg
│   ├── photo8.jpg
│   └── photo9.jpg
```

## Как опубликовать на GitHub Pages

1. Создай новый репозиторий на github.com (например `rita-birthday`)
2. Загрузи все файлы (index.html + папку images + song.mp3)
3. Зайди в Settings → Pages → Source: выбери `main` branch → Save
4. Через 1-2 минуты сайт будет доступен по адресу:
   `https://твой-username.github.io/rita-birthday`

## Важно: музыка

Переименуй файл песни в `song.mp3` перед загрузкой на GitHub.
